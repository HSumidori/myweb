# 四中恋爱日记 · 单文件保底版

**所有素材都内联在这一个 `index.html` 里**（6.28 MB），不需要任何其它文件。
适合在"拆分素材版因为上传环节出问题"时使用——它不可能因为少传文件而坏掉。

## 部署

把 `index.html` 和 `.nojekyll` 放到仓库根目录，push 之后在
Settings → Pages 里选 `main` 分支 + `/(root)`。

> 注意：GitHub 网页端拖拽上传单文件上限是 25 MB，这个文件如果超了就用 git 命令行推。
> 命令行方式单文件上限 100 MB。

## 本地预览

单文件版**可以直接双击打开**（不需要 HTTP，因为没有外部素材）：

```
直接双击 index.html 即可
```

## 代价

首屏要等整包下载完（约 6.28 MB），所以它比拆分素材的版本慢。
能用拆分版就优先用拆分版。
